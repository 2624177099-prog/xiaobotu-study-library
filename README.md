# 小博土 · 期末资料库

学生个人维护的公开学习资料站。主站通过 /resources/ 链接到资料服务。网站使用原生 Worker ES 模块、D1（SQLite 兼容关系数据库）和非公开 R2 对象桶。浏览器通过站内文件入口读已发布附件。首次收录的两份 Word 保留原始字节，PDF 是从对应 Word 转换的阅读副本。首次访问写入对象桶及数据库，以后以数据库为准。本仓库按站点所有者要求公开迁移源码及首批公开附件。Git 历史会保留这些附件，站点撤回操作仅控制站内下载。

## 本地运行和测试
Node 24+，无 npm 安装步骤。运行 npm run build，再运行 npm test。设置 DEV_ADMIN_TOKEN 为自己生成的随机密码，运行 npm run dev。浏览 http://127.0.0.1:8787/resources，本地管理登录 http://127.0.0.1:8787/__local/login （用户名 dev、密码为上述变量）。开发环境只监听回环地址，剥离伪造身份头。修改源码后重新构建、重启。DATA_DIR 指定开发数据目录，默认 .local-data；正式环境禁止使用临时文件系统。PUBLIC_ORIGIN 只配置正式 HTTPS 站点地址。不要把本地服务直接作为公网服务器。

## 上线
运行 npm run build，构建入口 dist/server/index.js。项目配置在 .openai/hosting.json，D1 绑定 DB、R2 绑定 BUCKET。部署产物包含 drizzle/ 中按顺序执行的迁移。Sites 的受信身份网关注入已验证的账号标识和邮箱，只有与服务端 ADMIN_EMAIL 匹配的已登录用户可以管理。PUBLIC_ORIGIN 填写正式域名。使用同一项目、同一数据库、同一桶部署更新；创建新项目或删除绑定会导致连接到不同的数据。首次部署前初始化 ADMIN_EMAIL，未设值时后台关闭。换所有者时替换该密钥。公开权限只对资料站生效。其他托管平台需先接入可验证身份的代理，并剥离外来身份头，再转发请求。迁移只新增文件，不能修改已经执行的 SQL。

## 日常操作
进入 /admin 使用站点所有者账号登录。新建资料，填写科目、适用学年、来源、AI 与核对说明，选择文件，确认授权后保存草稿，核对附件再发布。新投稿进入待审核，可下载检查并选择发布或退回。编辑元数据用于更正标题、说明、科目和标签。涉及正文变更时上传新版本、更改版本号并写修订说明。已发布资料的新版本保存后即时成为当前版本。旧版默认停止公开下载，按需允许。单附件可撤回，整条资料可撤回或归档；两者都停止访客下载，保留审计与可恢复记录。彻底删除属于离线维护，不提供误触即删除的页面按钮。反馈状态独立于发布和核对状态。
 
## 备份及恢复
在管理员浏览器访问 /api/admin/backup 下载包含数据库行、附件、支付码的 NDJSON。建议在大批量更新前备份，存放在私人加密目录，包含未公开联系方式。备份最后一行必须含 complete:true。运行 node restore.mjs 备份文件.ndjson 新数据目录，会检查表、附件长度、文件集合及结束标记，恢复到新目录。DATA_DIR 指向恢复目录启动服务，检查两份资料和私人待审核数据，再切换流量。现有线上数据不被本地恢复覆盖。迁回云端时，在新私有目标初始化 schema，将备份表按 restore.mjs 顺序导入 D1，按记录 key 上传原始二进制至 R2；验证后切换绑定。公网迁移及灾备演练需目标环境权限。对象可能在写入后进程被中断；管理员可同源 POST /api/admin/cleanup（JSON 空对象），携带返回的 cursor 分页清理超过 24 小时且完全无引用的对象。文件和数据库须一起备份。
 
## 数据和限制
来源、AI 参与和核对记录分开填写。分类和标签由资料元数据生成，避免出现空分类。管理员身份配置在托管设置，后台以同源 POST、服务端角色校验、大小限制、私有文件授权、按小时限流及提交幂等保护写入。无恶意软件扫描。上传格式、数量、尺寸在 src/files.js 集中配置。Office 文件检查实际 ZIP 目录/内容类型入口等，禁止宏和嵌入程序；PDF、图片检查文件签名。分页和组合筛选由前端处理，目录较大时再改为服务端分页、搜索。仅统计访问请求及文件请求，不去重为人数。二维码为站内生成，未配置正式地址时隐藏。收款码只按配置展示，无支付回调或金额确认。已收录 2024 级同学整理的往年资料。核对范围待补充。

## 验收记录
HTTP 集成测试覆盖中文 PDF/Word 上传、草稿发布、独立访客下载、二进制逐字节比对、跨进程持久化、反馈隐私、旧版开关、附件撤回、匿名投稿隔离、后台鉴权、同源校验、错误文件与不存在的文件。运行 npm test 可复测。实际 PDF 页数分别为 30 和 45；读者无需注册或付款。生产环境另以独立浏览器验证目录、讲义详情、PDF 预览地址及 Word 下载事件；手持真机、校园网络、所有者首次登录仍需用户环境实测。

## GitHub 迁移状态

本仓库包含最新源码、全部数据库迁移、14 份首批公开资料及 16 个附件。运行中的数据库、匿名留言、私密反馈、待审投稿和管理凭证均由原站持有，需要管理员单独导出完整备份并迁入新服务。GitHub Pages 可托管公开资料的只读快照，完整站需支持 Worker、持久数据库、对象存储以及可信身份认证的后端。

公开附件在 Git 历史中可长期存在。已撤回或受限资料不应继续同步到公开仓库。正式迁移服务前需验证匿名浏览、附件字节一致性、后台鉴权和私密数据隔离。

### 启用 GitHub Pages 资料备用页
仓库 Settings → Pages → Build and deployment → Deploy from a branch，选择 main 和 /docs，保存。docs 为 2026-11-15 的首批公开资料快照，提供浏览和真实附件下载。留言、投稿和管理操作需完整后端。访问表现需要在同学手机网络里实测。站点当前数据库的后来新增或已撤回资料不在此快照同步范围内。
